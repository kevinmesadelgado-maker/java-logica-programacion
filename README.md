
# Proyecto: Fundamentos de Java

Este proyecto contiene ejemplos básicos de programación en Java organizados en diferentes clases.  
Cada clase demuestra un tema fundamental del lenguaje.

La clase principal **App.java** ejecuta todos los ejemplos para mostrar su funcionamiento.

---

# Estructura del Proyecto

El proyecto contiene **12 clases** que explican diferentes conceptos de Java.

## 1. VariablesYConstantes
Demuestra:
- Declaración y asignación de variables
- Convenciones de nombres (camelCase)
- Uso de constantes con `final`

## 2. TiposDeDatosPrimitivos
Ejemplos de tipos primitivos:
- `byte`
- `short`
- `int`
- `long`
- `float`
- `double`
- `char`
- `boolean`
- Valores por defecto

## 3. ConversionDeTipos
Demuestra:
- Casting implícito
- Casting explícito
- Posible pérdida de precisión

## 4. Operadores
Ejemplos de:
- Operadores aritméticos
- Incremento y decremento
- Operadores relacionales
- Operadores lógicos
- Operador ternario

## 5. EntradaDeDatos
Uso de la clase `Scanner` para:
- Leer números
- Leer texto
- Manejar problemas con `nextLine()`

## 6. EstructurasCondicionales
Ejemplos de:
- `if`
- `if - else`
- `if - else if`
- `switch`

## 7. EstructurasDeRepeticion
Ejemplos de ciclos:
- `while`
- `do-while`
- `for`
- `for` anidados
- Uso de `break` y `continue`
- Uso de etiquetas

## 8. MetodosEstaticosSimples
Demuestra:
- Métodos sin parámetros
- Métodos con parámetros
- Métodos con retorno
- Sobrecarga de métodos

## 9. ArreglosUnidimensionales
Ejemplos de:
- Declarar arrays
- Usar `.length`
- Recorrer con `for`
- Recorrer con `for-each`

## 10. ArreglosBidimensionales
Demuestra:
- Declaración de matrices
- Recorrer matrices con `for` anidados

## 11. ManipulacionCadenas
Uso de `String`:
- Concatenación
- Métodos útiles (`length`, `substring`, `toUpperCase`, etc.)
- Inmutabilidad de `String`
- Uso de `StringBuilder`

## 12. ManejoBasicoExcepciones
Manejo de errores con:
- `try-catch`
- `ArithmeticException`
- `InputMismatchException`
- `finally`
